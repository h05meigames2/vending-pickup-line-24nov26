[One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee)
— one pickup line, at most 200 characters, spoken by a vending machine to a
passing human.

## The line

> Insert coin, press B7 — I've vended a thousand snacks, but you're the
> first one my coils ever refused to drop.

## How it works

`main.py` (Python 3.13, standard library only) writes that single line,
deterministically, to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when set). No network, no dependencies.

```sh
python3 main.py
```
